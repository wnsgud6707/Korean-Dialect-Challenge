제주 방언

“왕 봅서. 고랑은 몰라 마씀.”

표준어 뜻 확인하기

“와서 보십시오. 말로 해서는 모릅니다.”

표현과 뜻 출처: 국제신문 「제주의 향기를 찾아 생태기행」. 이 문장은 소개를 위한 예시이며 모델의 변환 결과가 아닙니다.

제주 방언에 익숙하지 않다면, 짧은 문장도 뜻을 바로 짐작하기 어려울 수 있습니다. 음성 서비스 역시 사용자의 지역별 말투를 충분히 다루지 못하면 요청을 잘못 받아들일 수 있습니다.

말투가 달라도 알아듣는 음성 서비스

같은 요청도 지역에 따라 발음과 억양, 사용하는 단어가 다릅니다. 표준어 위주로 학습한 음성인식 모델은 이런 차이를 충분히 반영하지 못할 수 있습니다. 사용자가 익숙한 말투로 이야기했는데 시스템이 다른 말로 받아들이거나, 같은 요청을 여러 번 되묻게 되는 것입니다.

음성으로 기기를 조작하거나 안내를 받는 서비스라면 사용자가 기계에 맞춰 말투를 바꾸지 않아도 되어야 합니다. 일상에서는 차량 내 음성 조작이나 전화 상담에, 현장에서는 재난 대응과 작업 지시 전달에 이런 요구가 있습니다. 국방 분야의 음성 통신에서도 지역별 말투 때문에 지시 내용을 잘못 인식하는 상황을 줄이는 것이 중요할 수 있습니다.

이 과제는 그 출발점으로 방언의 지역을 분류하고, 음성에 담긴 내용을 표준어 텍스트로 옮기는 두 작업을 다룹니다. 지역마다 어떤 오류가 생기는지 비교하고, 다양한 말투를 처리하는 음성인식 모델을 개선하는 것이 목적입니다.

여기서 평가하는 범위는 지역 분류와 표준어 텍스트 변환입니다. 실제 서비스에 적용하려면 소음·무전 음질·전문용어를 포함한 환경에서 추가로 검증하고, 명령을 정확히 이해했는지 확인하는 절차도 필요합니다.

무엇을 하는 과제인가요?

AI-Hub의 다섯 지역 방언 데이터를 이용했습니다. 하나의 음성 파일을 입력하면 지역 이름과 표준어 문장을 출력합니다. 지역 분류는 Macro F1, 표준어 변환은 문자 오류율(CER)로 따로 평가합니다.

선별 및 이용 기준

지역별로 화자의 연령·성별 분포와 녹음 수에 차이가 있습니다. 직접 듣고 확인하는 청취 검수는 진행하지 못했습니다.

원본 음성과 전사 원문은 재배포하지 않습니다. 참가자가 AI-Hub 이용 승인을 받은 뒤 지정 파일을 직접 내려받아 복원합니다. 비공개 평가의 선정 목록과 정답은 배포하지 않습니다.

Baseline

제공한 모델을 실행한 뒤, 분류 성능과 표준어 변환 성능을 개선합니다.

01. 방언 식별

16kHz 음성→Wav2Vec-BERT 2.0→Classification Head→5개 지역

Wav2Vec-BERT 2.0의 Encoder는 고정하고 Classification Head만 학습합니다. Encoder가 추출한 특징을 저장해 다음 epoch에서 재사용합니다. Validation Macro F1이 가장 높은 체크포인트를 선택합니다.

학습 파라미터Head 791,045개
설정Seed 42 · 최대 10 epochs · LR 1e-4
실측 학습 시간28분 · 특징 추출 약 22분 포함

RTX 4070 12GB 기준. 파일 사전 검증과 모델 다운로드는 별도이며 장비에 따라 달라집니다.

python scripts/baseline.py preflight --config configs/baseline_participant_v2.json
python scripts/baseline.py train --config configs/baseline_participant_v2.json
python scripts/baseline.py evaluate --config configs/baseline_participant_v2.json --split public_test

02. 음성 → 표준어 텍스트

입력 음성→Whisper large-v3-turbo→어절 치환 규칙→표준어 텍스트

Whisper로 음성을 텍스트로 바꾼 뒤, 방언 표현을 표준어로 치환합니다. 치환 규칙은 Train의 방언·표준어 문장 쌍에서 학습했습니다. Whisper는 추가 학습 없이 사용했으며, 모델과 규칙 설정은 Validation CER를 비교해 선택했습니다.

python experiments/standardization_v1/download_models.py asr_turbo
python experiments/recording_v2/standardize.py train --participant
python experiments/recording_v2/standardize.py asr --model asr_turbo --participant
출력은 표준어 텍스트입니다. 표준어 음성을 생성하는 TTS 기능은 포함하지 않습니다.

Macro F1

다섯 지역의 F1을 각각 계산한 뒤 평균합니다. 발화 수가 적은 지역도 같은 비중으로 평가합니다.

CER · WER

오류율은 (대체 + 삭제 + 삽입 횟수) / 정답 길이로 계산합니다. 모든 문장의 오류 수와 정답 길이를 각각 합산해 구합니다. 평가 전에 유니코드를 NFC로 정규화하고 문장부호를 공백으로 바꾼 뒤 연속된 공백을 정리합니다. CER는 공백을 뺀 문자 단위로, WER는 공백으로 구분한 어절 단위로 계산합니다.

CER는 문자열 오류율입니다. 의미가 같은 다른 표현도 오류로 계산할 수 있으므로 1−CER를 번역 정확도로 해석하지 않습니다.

처리 시간 측정 조건

저장된 WAV 파일을 읽는 시점부터 지역 분류와 표준어 변환이 끝날 때까지 측정합니다. 음성 한 개씩 처리하며(batch size 1), 측정 전에 한 번 실행해 워밍업합니다. GPU 연산이 끝난 시점을 정확히 재기 위해 측정 구간 전후에 동기화합니다.

모델 로드·JSON 저장·녹음·네트워크 업로드 시간은 제외합니다. RTF는 전체 처리 시간 / 전체 입력 음성 길이입니다. 스트리밍 첫 응답 지연과는 다른 지표입니다.

처리 속도는 운영자가 같은 장비에서 다시 측정해 비교합니다.

예측 파일 형식

JSONL 한 줄에 아래 세 필드만 넣습니다. 예시 ID와 문장은 형식 설명용입니다.

{"sample_id":"example_0001","prediction":"gyeongsang","standard_text":"오늘 날씨가 좋습니다."}

지역 라벨: gyeongsang, jeolla, chungcheong, gangwon, jeju

ID 누락·추가·중복, 잘못된 지역 키와 추가 필드는 채점 오류로 처리합니다. 입력 파일에는 sample_id와 음성 상대경로 path가 제공됩니다.

공정한 비교를 위한 규칙

기본 트랙은 지정 Train으로 학습하고 Validation으로 설정을 선택합니다. 사전학습 모델은 허용하며 모델명·revision·학습 설정을 기록합니다. 추가 데이터 사용은 별도로 표시합니다.

같은 AI-Hub 원천 ZIP에 평가 음성이 들어 있을 수 있습니다. 따라서 원천 ZIP 전체를 추가 학습에 사용하는 것은 기본 트랙 범위를 벗어납니다. 비공개 평가 선정 목록과 정답은 운영자가 관리합니다.

제출된 예측 파일은 운영자가 평가 코드로 채점합니다. 이 페이지에는 파일 업로드나 자동 채점 기능이 없습니다.

자주 묻는 질문

왜 5GB 데이터를 만들기 위해 66.88GB를 받나요?

AI-Hub 다운로드 단위가 원천 ZIP이기 때문입니다. 지정 ZIP 11개에서 선정된 구간만 복원합니다. 전체 데이터셋을 다운로드하지 않습니다.

같은 녹음의 서로 다른 구간이 Train과 Test에 들어가나요?

아니요. 같은 녹음에서 자른 발화는 모두 같은 데이터셋에 넣었습니다. 내용이 동일한 음성 파일도 함께 묶었습니다. 다만 다른 녹음에 같은 사람이 참여했는지는 확인할 수 없습니다.

음성으로 표준어를 들을 수 있나요?

현재 표준어 변환의 출력은 텍스트입니다. 음성 합성 기능은 포함하지 않습니다.

다른 모델이나 추가 데이터를 써도 되나요?

사전학습 모델 사용은 허용합니다. 추가 학습 데이터가 있다면 출처와 범위를 기록하며, 지정 Train만 사용하는 기본 트랙과 구분합니다.

# recording-v2 최종 baseline — 2026-10-25

## 데이터와 학습

기존 v1은 보존하고 v2를 별도로 구성했다. 총 30,443개, 43.42시간, WAV 5,002,880,756 bytes. Train 21,222 / Validation 3,120 / 공개 Test 3,043 / 비공개 Test 3,058이다. 원본 녹음·동일 WAV·동일 PCM의 split 간 중복은 0건이다. 전역 화자 독립은 확인되지 않았고 사람의 청취 검수는 수행하지 못했다.

분류는 Encoder Freeze, head 791,045 parameters, best epoch 10이다. 학습 실측 1680.10초, 그중 특징 추출 1327.24초. 사전 파일 검증과 모델 다운로드는 학습 타이머와 별도다.

표준어 출력은 Whisper large-v3-turbo와 Train에서 학습한 어절 치환 규칙이다. ASR 모델 자체는 추가 학습하지 않았다. 두 전사 모델 비교 및 규칙 설정은 Validation만 사용했고, 그 뒤 모델·규칙·코드 해시를 고정했다. 테스트 성적을 보고 추가 튜닝하지 않았다.

Validation 전사 비교는 batch 4, 최종 joint Test는 batch 1이다. 분류와 변환은 각각 순위를 제시하며 합성 점수를 만들지 않는다. CER는 문자열 오류율이며 의미 정확도와 다르다. 문장부호·공백·NFC 정규화와 corpus 합산 방식을 사용한다. 비식별 표기와 숫자 표현 차이의 영향을 포함한다.

## 재현과 보존

학생용 공개 27,385개를 별도 경로에서 실제로 모두 복원했고 WAV 체크섬이 일치한다. Train/Validation 텍스트도 라벨 ZIP에서 복원했으며 학생 경로에서 재학습한 변환 규칙과 검증 결과가 운영자와 바이트 단위로 일치한다. 다운로드는 지정 ZIP 11개, 약 66.88GB다. 모든 원본 ZIP을 다시 다운로드한 검증은 아니며 이미 확보한 동일 ZIP을 사용한 복원 검증이다.

모든 결과는 로컬에 보관한다. 공개 후보는 코드·설정·공개 메타데이터만 포함한다. 개별 비공개 입력 ID·예측·정답은 포함하지 않는다. 교수님 전달 ZIP과 GitHub 업로드는 아직 하지 않았다. 홈페이지는 참고 사이트 수령 후 진행한다.
